git.pp playground

A single-page browser playground for the git.pp fold. Edit records on the left, see the closure root, derived state, and conflicts on the right. Powered by gitpp-js. The JS in src/gitpp.browser.js is a drop-in replacement for the Node version (it uses window.crypto.subtle instead of node:crypto).
